# B站听歌列表使用指南

## 运行要求

- Chrome 或 Edge 109 及以上版本。
- 播放部分高音质或受限内容时，需要先在浏览器中登录 B站。
- 扩展只在普通 `http://` 和 `https://` 网页中显示；浏览器设置页、新标签页和扩展商店等受保护页面不会显示悬浮按钮。

## 安装

1. 从 GitHub Releases 下载 `bilibili-music-player-v2.6.3.zip`，不要下载名称为 `Source code` 的自动源码包。
2. 将 ZIP 解压到一个准备长期保留的目录。
3. Chrome 打开 `chrome://extensions/`；Edge 打开 `edge://extensions/`。
4. 开启“开发者模式”，点击“加载已解压的扩展程序”。
5. 选择包含 `manifest.json` 的解压目录。

浏览器不能直接加载 ZIP。扩展加载后不要随意移动或删除解压目录，否则需要重新加载；更换目录还可能使浏览器把它识别成另一个未打包扩展。

## 更新

1. 先在播放列表菜单中选择“导出为 JSON”备份重要播放列表。
2. 下载新版本 ZIP，并用其中的文件替换原扩展目录内容。
3. 回到扩展管理页，点击本扩展卡片上的“重新加载”按钮。
4. 打开任意普通网页并刷新，确认扩展详情中的版本号已经更新。

使用相同目录和同一个扩展实例更新时，播放列表、音量、主题和面板位置会继续保存在浏览器本地。

## 打开播放器

- 点击网页右下角的音符按钮。
- 播放或暂停过内容后，音符会展开为迷你控制胶囊；点击右侧频谱区域可展开播放列表。
- 点击浏览器工具栏中的扩展图标。
- 使用 `Ctrl+Shift+B`；macOS 使用 `Command+Shift+B`。

如果快捷键与其他扩展冲突，可在 `chrome://extensions/shortcuts` 或 `edge://extensions/shortcuts` 中重新设置。

## 添加歌曲

1. 打开 B站视频页面。
2. 展开播放器面板。
3. 点击面板顶部的“＋加入”。

扩展会读取当前视频或当前分 P 的标题、封面和音频信息，并添加到当前播放列表。相同 `bvid + cid` 的条目不会重复添加；非 B站视频页面不会显示“＋加入”按钮。

## 导入合集或多 P

1. 打开 B站合集中的任意视频，或打开一个普通多 P 视频。
2. 展开播放器面板，等待顶部出现“全部加入”。普通单视频不会显示该按钮。
3. 点击“全部加入”，确认合集标题和视频数量。
4. 选择导入当前播放列表，或创建一个以合集标题命名的新播放列表。
5. 点击“确认导入”，等待界面显示新增和跳过的数量。

导入顺序与 B站接口返回的分区、剧集和分 P 顺序一致。非嵌套条目使用分 P 名称；只有合集中的视频自身包含多个分 P 时，才会使用“视频标题 · 分 P 名称”避免重名。扩展会按 `bvid + cid` 去重，导入当前播放列表时不会重复添加已有条目；导入为新播放列表后会自动切换到新播放列表。大型合集可能需要数秒完成，请等待明确的成功或失败提示后再关闭页面。

确认导入时可以勾选“智能重命名”。扩展会先按标题分段，移除明显的括号元数据和超过十个字符的可疑文案，再从本次合集的全部标题中识别公共前缀或后缀。过滤后只剩一个长片段时会保留它，避免产生空标题。统一前缀为可选项，例如输入“周杰伦”后会得到“周杰伦 - 晴天”。规则文件中的示例默认关闭；高级用户可以在 `src/rename/rules.json` 中启用或添加静态正则替换规则，规则只包含 JSON 数据，不执行脚本。

该功能面向 `/video/BV...` 页面中的 UGC 合集、列表和普通多 P 视频。付费、地区限制、已失效或当前账号无权访问的条目仍可能在实际播放时失败。

## 播放控制

- 点击播放列表中的条目开始播放。
- 播放器提供上一首、播放/暂停、下一首、停止、进度和音量控制。
- “暂停”保留当前歌曲和进度；“停止”结束当前播放并让迷你播放器回到紧凑状态。
- 点击播放模式按钮可依次切换：顺序播放、随机播放、单曲循环、列表循环、随机循环。
- 关闭或跳转当前网页后，音乐仍由扩展的后台音频文档继续播放；完全关闭浏览器会停止播放。

## 管理播放列表

- 使用播放列表栏的“＋”新建播放列表，使用下拉框切换播放列表。
- 点击歌曲右侧的铅笔图标可重命名；按 Enter 保存，按 Esc 取消。
- 按住封面并上下拖动可调整歌曲顺序。
- 封面悬停约一秒会显示放大预览。
- 长按歌曲文字区域约半秒进入批量选择，可移动、复制或删除多首歌曲。
- 点击播放列表栏的“⋯”可重命名、清空或删除播放列表，并可导入、导出播放列表。

JSON 是当前播放列表的备份与恢复格式；TXT 和 Markdown 更适合阅读或分享。需要备份多个播放列表时，请分别切换并导出。导入的 JSON 至少需要为每个条目提供 `bvid`。

## 调整界面

- 拖动面板顶部的握把可移动播放器。
- 拖动右下角的两条斜线可调整面板尺寸。
- 点击顶部调色按钮可展开主题色块；选择结果会自动记忆。
- 点击播放器以外的网页区域会收起面板，但不会停止正在播放的音乐。

## 常见问题

### 网页上没有悬浮按钮

确认当前页面是普通网页，并在扩展管理页检查扩展是否已启用。安装或更新扩展后，已打开的网页需要刷新。浏览器内部页面不允许扩展注入播放器。

### B站页面没有“＋加入”

该按钮只在地址中包含 BV 号的 B站视频页显示。站内跳转后如果页面没有刷新，可刷新一次视频页。

### 合集页面没有“全部加入”

“全部加入”会在后台确认当前视频属于合集或包含多个分 P 后出现。请先确认网络正常并等待片刻；普通单视频、番剧播放页及 B站接口未返回合集信息的页面不会显示该按钮。

### 歌曲无法播放

先确认网络正常，并尝试登录 B站。部分高音质、大会员或地区受限内容取决于当前账号权限。也可以从播放列表“⋯”菜单打开“查看运行日志”，或导出日志后随 Issue 提交；公开日志前请移除账号、Cookie 和音频 URL 等敏感信息。

### 暂停较久后再次播放需要等待

Chromium 可能回收暂停状态下的后台音频文档。扩展会在再次播放时自动重建并恢复已保存的进度，短暂等待属于正常现象。

## 数据与权限

播放列表、播放状态、音量、主题、面板尺寸和诊断日志保存在 `chrome.storage.local`，不会由本项目上传到自有服务器。扩展需要访问 B站接口与音视频域名来获取条目信息和播放地址，并在普通网页中注入悬浮播放器。
