# B站听歌列表使用指南

## 运行要求

- Chrome 或 Edge 109 及以上版本。
- 只访问匿名可用的公开接口，不读取登录 Cookie；部分付费、会员或地区受限内容无法播放。
- 扩展只在普通 `http://` 和 `https://` 网页中显示；浏览器设置页、新标签页和扩展商店等受保护页面不会显示悬浮按钮。

## 安装

1. 从 GitHub Releases 下载最新版本 ZIP，不要下载名称为 `Source code` 的自动源码包。
2. 将 ZIP 解压到一个准备长期保留的目录。
3. Chrome 打开 `chrome://extensions/`；Edge 打开 `edge://extensions/`。
4. 开启“开发者模式”，点击“加载已解压的扩展程序”。
5. 选择包含 `manifest.json` 的解压目录。
6. 在扩展详情中将站点访问权限设为“在所有网站上”。权限受限可能同时导致浮层、播放或热榜请求不可用。

浏览器不能直接加载 ZIP。扩展加载后不要随意移动或删除解压目录，否则需要重新加载；更换目录还可能使浏览器把它识别成另一个未打包扩展。

## 更新

1. 确保 `update.bat` 位于包含 `manifest.json` 的扩展目录根部。
2. 双击 `update.bat`，脚本会从官方 GitHub Release 下载完整新版、校验并替换程序文件。
3. 更新完成后重启浏览器，或回到扩展管理页点击本扩展卡片上的“重新加载”按钮。
4. 打开任意普通网页并刷新，确认扩展详情中的版本号已经更新。

更新器会保留 `src/rename/rules.json` 中的用户规则。播放列表、音量、主题和面板位置由浏览器保存在本地，使用相同目录和同一个扩展实例更新时不会丢失。更新失败时会尝试恢复旧版文件。

通过 Git 克隆的源码目录请使用 Git 更新，自动更新器会拒绝覆盖源码。新版安装成功但旧备份清理失败时，会保留新版并显示备份位置；如部署失败且恢复也失败，请保留日志所示的备份目录，按提示恢复或下载完整发布包。

## 打开播放器

- 点击网页右下角的音符按钮。
- 播放或暂停过内容后，音符会展开为迷你控制胶囊；点击右侧频谱区域可展开播放列表。
- 点击浏览器工具栏中的扩展图标。
- 使用 `Ctrl+Shift+B`；macOS 使用 `Command+Shift+B`。

如果快捷键与其他扩展冲突，可在 `chrome://extensions/shortcuts` 或 `edge://extensions/shortcuts` 中重新设置。

## 添加歌曲

### 手动添加条目

1. 在播放列表栏点击“＋”。
2. 输入名称或搜索关键词，点击“确认”。
3. 新条目会先以默认封面显示；点击条目右侧的放大镜按钮，开始搜索并匹配 B 站音源。

匹配成功后会补齐封面、时长和播放链接，但保留你输入的标题。未匹配的手动条目不会在自动播放时联网，会被自动跳过；匹配失败时可以再次点击放大镜重试。

尚未匹配到来源时，重命名条目也会修改搜索关键词；已有来源时重命名只改变显示名称。手动匹配会检验候选媒体能否加载，失败后在有限时间和次数内继续尝试；网络持续异常时会结束并保留重试入口。

### 从 B站视频添加

1. 打开 B站视频页面。
2. 展开播放器面板。
3. 点击面板顶部的“＋加入”。

扩展会读取当前视频或当前分 P 的标题、封面和音频信息，并添加到当前播放列表。相同 `bvid + cid` 的条目不会重复添加；非 B站视频页面不会显示“＋加入”按钮。

## 导入合集或多 P

1. 打开 B站合集中的任意视频，或打开一个普通多 P 视频。
2. 展开播放器面板，等待顶部出现“全部加入”。普通单视频不会显示该按钮。
3. 点击“全部加入”，确认合集标题和视频数量。
4. 选择导入当前播放列表，或创建一个以合集标题命名的新播放列表。
5. 点击“确认导入”，等待界面显示新增和跳过的数量。

导入顺序与 B站接口返回的分区、剧集和分 P 顺序一致。非嵌套条目使用分 P 名称；只有合集中的视频自身包含多个分 P 时，才会使用“视频标题 · 分 P 名称”避免重名。扩展会按 `bvid + cid` 去重，导入当前播放列表时不会重复添加已有条目；导入为新播放列表后会自动切换到新播放列表。大型合集可能需要数秒完成，请等待明确的成功或失败提示后再关闭页面。

确认导入时可以勾选“智能重命名”。扩展会先按标题分段，移除明显的括号元数据和超过十个字符的可疑文案，再从本次合集的全部标题中识别公共前缀或后缀。过滤后只剩一个长片段时会保留它，避免产生空标题。统一前缀为可选项，例如输入“周杰伦”后会得到“周杰伦 - 晴天”。规则文件中的示例默认关闭；高级用户可以在 `src/rename/rules.json` 中启用或添加静态正则替换规则，规则只包含 JSON 数据，不执行脚本。

自定义规则支持普通字符、字符集、首尾锚点、非捕获组、分支和单字符量词；不支持捕获组、分组量词、前后查找或反向引用。不支持的表达式会跳过，不影响默认命名。详细语法见 [在线规则说明](https://github.com/randian-2008/bilibili-music-player/blob/main/docs/architecture.md#智能重命名)。

该功能面向 `/video/BV...` 页面中的 UGC 合集、列表和普通多 P 视频。付费、地区限制、已失效或不能匿名访问的条目仍可能在实际播放时失败。

## 导入热榜

1. 展开播放器面板，点击播放列表栏中的“热榜”。
2. 依次选择音乐平台、榜单分类和具体榜单。
3. 选择导入前 10、25 或 50 个条目，并按需修改播放列表名称。
4. 点击“确定”。窗口关闭后，扩展会创建并切换到新的播放列表。

当前支持 Apple Music、QQ 音乐和网易云音乐。榜单只提供排名、歌曲名和歌手名，不直接提供本扩展使用的音频。扩展会先显示“歌曲名 - 歌手”的占位条目，再通过 B站搜索匹配视频：匹配完成后显示 B站封面，标题仍保持热榜格式；尚未匹配的条目显示默认封面，匹配失败的条目显示失败标记。

点击确定后的等待主要用于读取所选榜单并一次性写入占位条目；导入过程不会等待整张榜单的 B站音源匹配。B站搜索暂时返回 HTTP 412 时，扩展会自动以递增间隔进行有限重试；如果仍未成功，条目会保留失败标记，之后可点击放大镜手动重试。

如果窗口提示后台响应超时，可以保持选项不变后重试确认；同一次导入会复用已创建的结果。

开始播放后，扩展会间隔处理后续条目。随机播放选中尚未匹配的条目时，会优先匹配该条目；自动匹配失败后会跳过，用户手动点击失败条目时会使用更宽的搜索范围重试。不同平台可能随时调整公开接口或榜单编号，因此某个平台或分类可能暂时不可用。

## 播放控制

- 点击播放列表中的条目开始播放。
- 播放器提供上一首、播放/暂停、下一首、停止、进度和音量控制。
- “暂停”保留当前歌曲和进度；“停止”结束当前播放并让迷你播放器回到紧凑状态。
- 点击播放模式按钮可依次切换：顺序播放、随机播放、单曲循环、列表循环、随机循环。
- 关闭或跳转当前网页后，音乐仍由扩展的后台音频文档继续播放；完全关闭浏览器会停止播放。

## 管理播放列表

- 使用播放列表栏的下拉框切换播放列表。
- 点击播放列表栏的“⋯”打开“更多操作”，可以新建、重命名、清空或删除播放列表，并可导入、导出播放列表。
- 点击歌曲右侧的铅笔图标可重命名；按 Enter 保存，按 Esc 取消。
- 按住封面并上下拖动可调整歌曲顺序。
- 封面悬停约一秒会显示放大预览。
- 长按歌曲文字区域约半秒进入批量选择，可移动、复制或删除多首歌曲。

JSON 是当前播放列表的完整备份与恢复格式，会保存音源、匹配目标、匹配历史和待匹配状态等内部条目信息；导入时会为播放列表和条目重新生成内部 ID。TXT 和 Markdown 只保留标题、UP 主、时长和链接等显式信息，更适合阅读或分享。需要备份多个播放列表时，请分别切换并导出。旧版 JSON 仍可继续导入；普通条目需要提供 `bvid`，未完成匹配的热榜条目可以通过榜单来源和标题恢复。

导入备份时，未完成的“匹配中”状态会恢复为待匹配，不会让搜索按钮永久禁用。

## 调整界面

- 拖动面板顶部的握把可移动播放器。
- 拖动右下角的两条斜线可调整面板尺寸。
- 点击顶部调色按钮可展开主题色块；选择结果会自动记忆。
- 点击播放器以外的网页区域会收起面板，但不会停止正在播放的音乐。

面板按可移动区域的横纵比例记忆位置，并在已打开的标签页之间同步。旧版像素位置仍可读取，实际拖动或缩放后保存为新版格式；单击握把和临时缩小浏览器窗口不会覆盖位置偏好。

## 常见问题

### 网页上没有悬浮按钮

确认当前页面是普通网页，并在扩展管理页检查扩展是否已启用。安装或更新扩展后，已打开的网页需要刷新。浏览器内部页面不允许扩展注入播放器。

### B站页面没有“＋加入”

该按钮只在地址中包含 BV 号的 B站视频页显示。站内跳转后如果页面没有刷新，可刷新一次视频页。

### 合集页面没有“全部加入”

“全部加入”会在后台确认当前视频属于合集或包含多个分 P 后出现。请先确认网络正常并等待片刻；普通单视频、番剧播放页及 B站接口未返回合集信息的页面不会显示该按钮。

### 歌曲无法播放

先检查扩展的站点访问权限是否为“在所有网站上”，再确认网络正常。本扩展匿名请求音源，登录 B站不会改变扩展的访问权限。也可以从播放列表“⋯”菜单打开“查看运行日志”，或导出日志后随 Issue 提交；公开日志前请移除账号、Cookie 和音频 URL 等敏感信息。

### 热榜无法读取或部分条目匹配失败

先确认对应音乐平台和 B站均可正常访问。榜单接口由第三方平台维护，可能调整或临时限制访问；B站搜索遇到短暂的 HTTP 412 时扩展会自动重试，耗尽重试次数后再点击条目右侧的放大镜进行一次更宽范围的搜索。扩展不会使用第三方平台的音频、封面或播放链接。

### 暂停较久后再次播放需要等待

Chromium 可能回收暂停状态下的后台音频文档。扩展会在再次播放时自动重建并恢复已保存的进度，短暂等待属于正常现象。

## 数据与权限

播放列表、播放状态、音量、主题、面板尺寸和诊断日志保存在 `chrome.storage.local`，不会由本项目上传到自有服务器。扩展需要访问 B站接口与音视频域名来获取条目信息和播放地址；使用热榜功能时还会访问 Apple Music、QQ 音乐或网易云音乐榜单接口，并在普通网页中注入悬浮播放器。
